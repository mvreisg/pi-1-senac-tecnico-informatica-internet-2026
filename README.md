## Sobre

Projeto Integrador: Desenvolvedor Front-end da turma da manhã do curso Técnico em Informática para Internet de 2026 do Senac Barretos.
A ideia central por trás dele é o Confirma, o nosso sistema de gestão de pedidos e entregas que integra estabelecimento, entregadores e clientes.
Apenas o Frontend foi desenvolvido, sendo utilizado HTML, CSS e JavaScript.
A logo também é autoral, sendo projetada no Adobe Illustrator.
